# AGEPRO CoreLib 

AGEPRO CoreLib (Core Library) is an object-oriented helper libary for [AGEPRO-GUI](https://github.com/nmfs-ost/AGEPRO-GUI), that handles data stuctures based on the `AGEPRO VERSION 4.25` and `AGEPRO VERSION 4.0` Input File formats.

The intent for this repository is to modularize the GUI and non-GUI functionalities.

## About AGEPRO

> [!NOTE]
> For more information of AGEPRO for production use, please refer to _AGEPRO Reference Manual_ or the [source code repository](https://github.com/noaa-pifsc/AGEPRO) for the AGEPRO Calcuation Engine. 

AGEPRO (Age Structured Projection Model) is a program designed to evaluate the likely population consequences of complex harvest scenarios under alternative hypotheses about the stock-recruitment relationship. Uncertainty in initial population size at age is incorporated into the model.
